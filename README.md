# 🛍️ Nykaa E-commerce Analytics Dashboard

## 📌 Project Overview
An interactive e-commerce analytics dashboard built using Tableau to explore sales performance, analyze customer trends, and visualize key business metrics.

🎯 Project Objectives
- Analyze e-commerce sales performance.
- Explore customer and product trends.
- Identify patterns in business performance.
- Present insights through interactive visualizations.

🛠️ Tools & Technologies
- Tableau — Data visualization and dashboard development
- Data Analytics — Business metrics exploration and trend analysis

 📊 Dashboard Features
- Interactive charts and visualizations
- Filters for exploring data
- Sales performance analysis
- Customer and product trend exploration
- Visual summaries of key business metrics

 💡 Business Value
The dashboard helps users explore e-commerce performance, understand customer and product trends, and support data-driven business decisions.
